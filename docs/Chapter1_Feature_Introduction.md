# 第一章 功能介绍

## 1.1 系统概述

Story Compiler 是一个面向长文本创作场景的可控分镜与视觉预演系统。系统以“故事编译”为核心思想，将用户输入的自然语言故事自动解析为结构化叙事表示，并进一步生成角色设定、场景设定、镜头级分镜计划和关键帧视觉结果，最终形成可编辑、可预览、可导出的视觉预演项目。

与传统“输入文本直接生成图像或视频”的方式不同，本系统更强调长故事场景下的结构化、可控性、一致性和可编辑性。系统首先对故事进行语义分析，抽取角色、场景、事件和情绪线索；随后对故事进行镜头级规划，生成可编辑的 storyboard；在此基础上，系统结合角色/场景记忆和生成约束生成关键帧结果，并对生成结果进行一致性检查，支持用户进行局部修改和增量重生成。

本系统适用于以下场景：

- 长文本故事的视觉预演
- 分镜脚本的自动生成与编辑
- 创意内容的前期概念验证
- 可控的多镜头内容生成与展示

## 1.2 系统总体功能

本系统围绕“故事输入—结构解析—分镜规划—内容生成—结果评估—预览导出”的主流程展开，主要包含以下功能：

### （1）故事输入与项目创建功能
用户可以新建项目，输入完整故事文本、剧情梗概或剧本片段，并设置项目名称、目标风格等基础信息。系统以项目为单位管理所有生成过程和结果。

### （2）故事结构解析功能
系统自动分析输入故事，提取角色、场景、事件和情绪变化等关键信息，形成结构化叙事中间表示，为后续分镜生成和视觉规划提供基础。

### （3）角色与场景设定功能
系统根据故事内容自动生成角色卡和场景卡，并允许用户对角色外观、服装、关系、场景环境、氛围风格等信息进行人工修订，以增强结果的可控性。

### （4）分镜规划功能
系统根据故事情节自动生成镜头序列，形成镜头级 storyboard。每个镜头包含叙事目的、场景、主体、动作、情绪、构图等信息，并支持逐镜头查看与编辑。

### （5）关键帧生成功能
系统根据分镜结果和约束信息生成镜头关键帧，用于表达每个镜头对应的视觉效果。生成结果与镜头一一对应，便于后续统一管理和预览。

### （6）一致性检查功能
系统对关键帧结果进行角色一致性、场景一致性、风格一致性和叙事动作覆盖等方面的检查，辅助发现多镜头生成中的偏差问题。

### （7）局部编辑与重生成功能
用户可以对角色设定、场景信息、单个镜头或局部提示信息进行修改，系统支持针对受影响部分进行局部重生成，而无需整体重新计算。

### （8）预览与导出功能
系统支持对镜头序列和关键帧结果进行统一预览，并可输出可继续编辑的项目状态，为后续扩展到视频拼接与成片导出提供基础。

### （9）项目管理与历史仓库功能
系统支持查看历史项目、最近打开项目和项目状态，方便对已生成内容进行回溯、复用和继续编辑。
